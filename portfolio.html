About

Two disciplines, one build process.

I believe good code should feel simple, even when it's solving something complex.

I started out building websites — learning HTML, CSS, and JavaScript by rebuilding sites for local businesses and friends. Over the past year I've moved into building AI agents, combining that web foundation with tools like the OpenAI and Claude APIs to create assistants that can actually take action, not just chat.

As a developer still early in my career, I focus on shipping small, working versions first and improving from there. I write clean, readable code, communicate clearly about scope and timelines, and I'm upfront when something needs more research before I commit to it.
